# 👤 User Stories - The Cabbage Mail

## Category: Self-Service Registration & Authentication
- **US-00**: *As a new Business Owner*, I want to sign up for an account on the homepage so that I can independently access the email marketing platform without waiting for manual admin approval.
- **US-01**: *As a Registered User*, I want to log into my account with my email and password so that I can access my workspace securely.
- **US-02**: *As a Registered User*, I want to set up my sender email and AWS SNS settings in my account preferences so that my emails originate from my domain.

## Category: Audience & Contact Management
- **US-03**: *As a User*, I want to upload a CSV file of contacts into a subscriber list so that I don't have to add contacts manually.
- **US-04**: *As a Subscriber*, I want an easy one-click unsubscribe link in received emails so that I can opt-out whenever I choose.

## Category: Campaign Composition & Delivery
- **US-05**: *As a User*, I want to draft a minimalist HTML email campaign and preview it before sending.
- **US-06**: *As a User*, I want to send a campaign using AWS SNS infrastructure so that emails deliver reliably without maintaining server infrastructure.
- **US-07**: *As a User*, I want to see real-time delivery status (Sent, Bounced, Failed) for my campaigns on my dashboard.
