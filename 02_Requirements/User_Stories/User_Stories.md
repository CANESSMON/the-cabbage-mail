# 👤 User Stories - The Cabbage Mail

## Category: Client Onboarding
- **US-01**: *As an Agency Admin*, I want to add a new Client account with their name, sender email, and AWS settings so that I can manage email marketing for them separately.
- **US-02**: *As an Admin*, I want to switch between client workspaces with one click so that I can manage each client's campaigns efficiently.

## Category: Audience & Contact Management
- **US-03**: *As a Client Manager*, I want to upload a CSV file of contacts into a subscriber list so that I don't have to add contacts manually.
- **US-04**: *As a Subscriber*, I want an easy one-click unsubscribe link in received emails so that I can opt-out whenever I choose.

## Category: Campaign & Delivery
- **US-05**: *As a Client Manager*, I want to draft a minimalist HTML email campaign and preview it before sending.
- **US-06**: *As a Client Manager*, I want to trigger a campaign send using AWS SNS infrastructure so that emails deliver reliably without maintaining servers.
- **US-07**: *As a Client Manager*, I want to see real-time delivery status (Sent, Bounced, Failed) for sent campaigns.
